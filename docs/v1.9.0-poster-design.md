# v1.9.0 商品长图生成 — 详细设计方案

## 一、核心需求

闲鱼商品页只能传 9 张图，但同一类目下有很多商品要展示。需要一张长图把同类多个商品拼在一起，上传到闲鱼商品详情页。

两种场景：
1. **分类合集长图**：按 category 生成，展示该分类下所有活跃商品
2. **固定合集长图**：按 bundle 商品生成，展示子商品列表 + 打包价

## 二、技术方案

**Jinja2 渲染 HTML → Playwright 无头截图 → 返回 PNG**

新增依赖：`jinja2`、`playwright`（首次部署需 `playwright install chromium`）

## 三、文件结构

```
backend/
├── templates/
│   └── posters/
│       ├── base.html              ← 公共CSS + 布局骨架
│       ├── category-poster.html   ← 分类合集长图（extends base）
│       ├── bundle-poster.html     ← 固定合集长图（extends base）
│       ├── theme-parchment.html   ← 羊皮纸主题CSS（include 进 base）
│       └── theme-dark-gold.html   ← 深色暗金主题CSS（include 进 base）
├── services/
│   └── poster_service.py          ← 数据查询 + Jinja2渲染 + Playwright截图
└── routers/
    └── posters.py                 ← 新增路由

frontend/src/views/
└── PosterGenerator.vue            ← 独立长图生成页面
```

## 四、API 设计

### 分类合集长图

```
GET /api/posters/category?category=token&template=parchment&width=750
```

### 固定合集长图

```
GET /api/posters/bundle/{product_id}?template=parchment&width=750
```

### 预览（返回 HTML 而非截图，用于调试）

```
GET /api/posters/category?category=token&template=parchment&preview=true
```

### Query Params

| 参数 | 值 | 默认 | 说明 |
|------|-----|------|------|
| `category` | `counter` \| `token` \| `other` | 必填 | 分类合集时必填 |
| `template` | `parchment` \| `dark-gold` | `parchment` | 模板风格 |
| `width` | `750` \| `1080` | `750` | 图片宽度（px） |
| `preview` | `true` | 无 | 可选，返回 HTML 预览 |

### Response

- 正常：`Content-Type: image/png`，`Content-Disposition: attachment; filename="{title}-poster.png"`
- preview：`Content-Type: text/html`

## 五、模板设计

### 模板A：羊皮纸（parchment）

复刻旧版风格，沿用旧版 `theme.css` 的克苏鲁触手装饰、羊皮纸背景、Cinzel + Noto Serif SC 字体。

**配色**：
- 背景：`#f4e4c1`（羊皮纸色），卡片：`#faf3e3`
- 边框：`#6b4423`（深棕），内边框：`#a67c52`（古铜）
- 标题文字：`#4a3728`，价格：`#8b0000`（深红）
- 金色强调：`#b8860b`

### 模板B：深色暗金（dark-gold）

现代风格，沿用 PrintFlow 诡镇暗金主题色，简洁卡片无触手装饰。

**配色**：
- 背景：`#0d0d0d`，卡片：`#1a1510`
- 金色强调：`#d4af37`，金色悬停：`#ffd700`
- 文字：`#d1d5db`，弱文字：`#9ca3af`
- 边框：`#8b6914`

## 六、长图内容结构

### 分类合集长图

```
┌─────────────────────────────────┐
│ ✧ {分类标题} ✧                  │  ← 硬编码标题模板：
│                                 │    counter → "诡镇奇谈 3D打印 计数器 合集"
│ ✅ 非偏远满30元包邮 | 1-5天发货   │    token   → "诡镇奇谈 3D打印 指示物 token合集"
│ ✅ 3D打印存在层纹等正常瑕疵       │    other   → "诡镇奇谈 3D打印 其他配件 合集"
│ ✅ 款式与数量私聊确认后，改价下单  │
├─────────────────────────────────┤
│ ┌──────────┐ ┌──────────┐      │
│ │ 商品名    │ │ 商品名    │      │  ← 2列网格
│ │ ¥{price} │ │ ¥{price} │      │
│ │ [照片]    │ │ [照片]    │      │
│ │ 配色: ■■  │ │ 配色: ■■  │      │
│ │ 内容物:   │ │ 内容物:   │      │
│ │ ◆ xxx ×n │ │ ◆ xxx ×n │      │
│ └──────────┘ └──────────┘      │
│ ...更多商品卡片...               │
├─────────────────────────────────┤
│ 本链接持续更新新品                │
│ 下单前可咨询款式与发货时间        │
└─────────────────────────────────┘
```

### 固定合集长图（bundle）

```
┌─────────────────────────────────┐
│ ✧ {bundle商品名} ✧              │
│ 打包价：¥{price_single}（非偏远包邮）│
│ ✅ 全套指示物一次配齐             │
│ ✅ 3D打印存在层纹等正常瑕疵       │
├─────────────────────────────────┤
│ ┌──────────┐ ┌──────────┐      │  ← 子商品卡片（无单价）
│ │ {子商品名} │ │ {子商品名} │      │
│ │ [照片]    │ │ [照片]    │      │
│ │ 配色: ■■  │ │ 配色: ■■  │      │
│ │ 内容物:   │ │ 内容物:   │      │
│ └──────────┘ └──────────┘      │
├─────────────────────────────────┤
│ 本链接持续更新新品                │
│ 单品总价：¥{sum} | 打包立省 ¥{save}│  ← 自动计算
└─────────────────────────────────┘
```

### 商品卡片元素

| 元素 | 数据来源 | 分类合集 | 固定合集 |
|------|----------|----------|----------|
| 商品名 | `products.name` | ✅ | ✅（子商品名） |
| 单价 | `products.price_single` | ✅ | ❌ |
| 商品照片 | `products.image` → base64 | ✅ | ✅ |
| 配色信息 | `products.colors` → `colors` 表 | ✅ | ✅ |
| 内容物 | `products.contents` | ✅ | ✅ |
| 打包价 | `products.price_single`（bundle 本身） | — | ✅（页面头部） |
| 节省金额 | `Σ子商品.price_single - bundle.price_single` | — | ✅（页面底部） |

## 七、数据映射（DB字段 → 模板变量）

| 模板变量 | 数据来源 | 说明 |
|----------|----------|------|
| `title` | category → 硬编码标题 / bundle.name | 页面标题 |
| `notices` | 硬编码 | 公告文案 |
| `products[].name` | `products.name` | 商品名 |
| `products[].price` | `products.price_single` | 单品售价（分类合集用） |
| `products[].image_b64` | `products.image` → 读文件转 base64 | 商品照片 |
| `products[].colors` | `products.colors` → `colors` 表 | 配色信息 |
| `products[].contents` | `products.contents` | 内容物清单 |
| `bundle_price` | `products.price_single` | 打包价（bundle 用） |
| `unit_total` | `Σ子商品.price_single` | 单品总价（bundle 用） |
| `savings` | `unit_total - bundle_price` | 节省金额（bundle 用） |

## 八、商品照片处理

`poster_service.py` 读取 `frontend/public/images/{filename}`，转为 base64 内嵌到 HTML `<img src="data:image/...;base64,...">`，避免 Playwright 截图时的路径问题。无图片的商品显示占位符。

## 九、配色信息展示逻辑

从 `products.colors` JSON 解析，关联 `colors` 表获取色卡：

| `products.colors` 中的 type | 展示方式 |
|-----------------------------|----------|
| `fixed`（固定） | 标签"固定配色：" + 色卡色块 + 颜色名 |
| `optional`（可选） | 标签"可选配色（默认XX）：" + 色卡色块 + 颜色名 |

## 十、前端页面（PosterGenerator.vue）

独立页面，侧边栏新增「长图生成」入口（Image 图标）。

```
┌─────────────────────────────────────────┐
│ 长图生成                                 │
├─────────────────────────────────────────┤
│                                         │
│  生成类型:  ○ 分类合集  ○ 固定合集       │
│                                         │
│  分类:     [counter ▼]  (分类合集时显示) │
│  合集商品: [Token合集包 ▼] (固定合集时)  │
│  模板:     [羊皮纸 ▼]                    │
│  宽度:     [750px ▼]                     │
│                                         │
│  ┌─────────────────────────────┐        │
│  │                             │        │
│  │     预览区域（iframe）       │        │
│  │                             │        │
│  └─────────────────────────────┘        │
│                                         │
│  [生成并下载]                            │
│                                         │
└─────────────────────────────────────────┘
```

交互流程：
1. 选择类型 + 参数 → 自动加载预览（iframe 显示 preview HTML）
2. 点击「生成并下载」→ 请求 PNG → 浏览器下载
